TORQ setup

Make your push keys

This page creates two keys in your browser. Nothing is sent anywhere. Do this once.

1. Public key (safe to share)

Put this in index.html as the value of VAPID_PUBLIC, and save it as Supabase secret VAPID_PUBLIC_KEY.

2. Private key (secret)

Never put this in index.html or share it. Save it only as Supabase secret VAPID_PRIVATE_KEY.
